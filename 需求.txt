患者端（SpringBoot+Vue）
患者端全局组件：左下角【立即挂号】快捷跳转按钮 + 右下角AI助手入口。
全局公共组件（所有页面都有）
左侧可收缩导航栏（收起为小图标）：个人头像及简称、首页、科室信息、医生团队、立即挂号、我的挂号、站内通知、个人中心。
全局左下角固定立即挂号按钮，点击跳转至立即挂号页面；
全局右下角固定AI助手入口，点击从右侧弹出AI助手抽屉：
智能咨询支持回答医院位置、停车、出诊时间等问题，也支持患者以文字、上传图片的多模态方式描述症状，AI辅助推荐对应挂号科室。
设计要点：AI仅作为业务辅助工具，不提供诊断，不可替代挂号与医生诊疗。
首页
布局从上到下：
打招呼卡片：展示登录用户昵称与欢迎语，右侧放置【立即挂号】按钮。
轮播Banner：展示医院公告、通知、线上问诊须知。
快捷功能区卡片：线上问诊预约（跳转立即挂号页）、线下门诊挂号（跳转立即挂号页）、快速签到（跳转我的挂号并切换至待就诊标签）、缴费中心（跳转我的挂号并切换至待付款标签）、查看报告（跳转我的挂号并切换至已完成标签）、科室快捷入口（跳转科室信息）、医生快捷入口（跳转医生团队）。
页面底部放置就诊须知提示：线上问诊不能替代急诊，急症请前往线下医院就诊。
科室信息
顶部搜索框；左侧科室分类列表，右侧科室卡片。
科室卡片展示科室简介、今日出诊医生数量；卡片链接跳转至医生团队页面，并自动带入科室筛选条件。点击科室卡片，弹窗展示科室详情。
医生团队
顶部查询栏，支持按姓名、科室、出诊类型（线上/线下）、出诊日期、时间段筛选。
医生卡片信息：头像、姓名、职称、擅长方向、出诊类型、剩余号源、【预约】按钮；点击预约跳转立即挂号页面，自动回填当前选中医生信息。提交挂号后生成挂号单，跳转我的挂号待付款页面。
立即挂号
顶部筛选区域：就诊类型单选（线上问诊 / 线下挂号）、科室选择（列出所有科室标签）、日期选择（默认当天）、时间段选择（上午/下午，前端分组展示，后端存储精确时段）、医生选择；选项联动刷新下方号源卡片列表，列表根据就诊类型自动过滤，只展示匹配的号源。
号源卡片展示医生、科室、时段、主治方向、剩余号源与挂号按钮。若选择非当日号源，点击挂号弹出确认提示：当前为预约挂号，确认预约？挂号成功弹窗提示，引导用户前往待付款页面缴费。
我的挂号
顶部标签切换：全部 / 待付款 / 待就诊 / 就诊中 / 已完成 / 已取消。挂号卡片标签区分：蓝色【线上问诊单】、橙色【线下面诊号】，卡片操作按钮随状态动态渲染。
待付款：支持日期筛选；展示就诊类型、医生、时间、费用；操作：立即付款、取消挂号。模拟支付，付款成功后订单流转至待就诊。
待就诊
分区展示【今日挂号】与【预约挂号】。
今日挂号：展示当日待就诊订单，两种订单均提供【签到】按钮；未到达出诊时间按钮置灰，后端同步校验。签到成功进入排队队列，展示排队序号。
过号规则：由医生端点击标记过号；患者端出现【申请恢复排队】按钮，仅可申请一次；再次过号则订单作废，不可重排。今日挂号支持取消挂号。
线上问诊单额外提供【进入诊室】按钮，到问诊时间点亮；点击打开医患图文聊天窗口，支持文字、图片发送，患者可提前留言描述症状；医生端内置AI模块，自动解析聊天内图文信息，生成症状摘要仅供医生查看。
预约挂号：带【预约】标记，支持日期筛选；操作：查看详情、取消挂号。
就诊中：仅医生端点击叫号后，排队订单流转至就诊中。线下展示排队信息、医生呼叫提示；线上自动进入图文问诊聊天页。
已完成：支持日期筛选；操作：查看医生填写的病历总结。
已取消/已过期：支持日期筛选，展示取消原因，无可用操作。
站内通知
双标签：系统通知、医院新闻。
系统通知：包含挂号成功、缴费提醒、签到提醒、过号提醒、停诊通知、替诊通知；支持标记已读，停诊、替诊为高优先级通知，患者根据通知自行选择是否重新挂号/取消挂号。带有红点提醒。点击通知，若关联挂号单则跳转至对应订单。
医院新闻：医院公告、门诊调整通知，仅浏览。
个人中心
展示头像、昵称、手机号；功能菜单：修改密码、隐私协议、关于系统、退出登录。
挂号主线链路：
首页 → 立即挂号 → 选择科室/医生、日期、就诊类型、时段 → 提交挂号 → 待付款 → 待就诊 → 就诊中 → 已完成
线下链路：患者付款 → 签到 → 排队 → 医生叫号面诊 → 医生端完成就诊
线上链路：患者付款 → 到达出诊时间 → 签到入队 → 可进入诊室留言说明情况 → 医生叫号 → 图文问诊 → 医生端完成就诊
备注：
患者右下角AI助手仅承担咨询、多模态导诊推荐科室功能，不生成预问诊病历，不绑定挂号单；症状提取、AI摘要模块部署在医生侧线上问诊诊室，自动解析医患对话图文，生成摘要仅医生可见；AI不提供诊断，全程为辅助工具。

医生端（SpringBoot+Vue）
核心定位：医生完成接诊问诊、病历录入、开单开药；查看个人排班；发起停诊申请；科主任拥有停诊/替诊审批权限；管理员拥有最终复核权限。
基础约束：
单条排班只能是线上问诊 或 线下面诊；
挂号费完成缴费后，挂号单才具备进入待接诊排队队列的资格；挂号费未缴纳的订单带有【挂号待缴费】标签，不进入接诊队列；
排队优先级：预约队列整体优先于当日挂号队列；同队列内按签到时间先后排序；过号重排时，预约号放回预约队列末尾，当日号放回当日队列末尾；接诊列表患者卡片标注「预约挂号/当日挂号」；
签到窗口：仅允许在【出诊开始前30分钟，至出诊结束前15分钟】内签到；该时段内未签到则由后端定时任务判定为爽约，爽约订单不可签到、不可申请恢复排队；
就诊中订单不参与排队重排；
替诊校验规则：科主任选择替诊医生时，校验该医生在该时段是否存在任意排班（线上、线下任意一种），存在排班则禁止选为替诊医生；
停诊审批驳回规则（任一条件触发自动驳回，出诊前24h硬限制优先级高于7天上限）：① 申请提交起超过7天未完成全部审批；② 距离出诊时间不足24h仍未完成全部审批。
页面清单：首页、待接诊列表、排班管理、站内通知、个人中心
全局组件：医生诊室AI助手（仅在问诊页面左侧常驻，多模态提取医患图文信息，生成症状摘要仅供医生参考，不生成诊断）
全局布局:左侧导航栏顶部为头像用户名，下面为首页、待接诊列表、排班管理、申请管理、站内通知、个人中心标签，可收缩，展示为小图标。
首页
欢迎提示词，展示今日排班信息，和患者端一致的轮播图，快捷入口
待接诊列表（核心页面）
展示当前医生今日排班下、已缴挂号费、成功签到进入排队的患者卡片。
患者卡片信息：挂号类型（预约/当日和线上/线下）、挂号时间、签到时间、患者基础信息；卡片支持快捷操作：查看该患者在本医生名下的历史挂号与病历记录。
线上问诊卡片操作：【叫号】；点击叫号后打开图文问诊诊室页面，后端开始5分钟计时；页面左侧为AI症状提取助手，中间是医患图文聊天区，右侧为病历编辑、开单开药面板；若患者提前在聊天框留言，医生可提前查看症状。叫号满5分钟患者无回复，【过号】按钮激活，医生可点击过号；过号后订单放回对应队列末尾，患者端复用一次恢复排队规则，再次过号订单作废。底部按钮：过号、查看历史病历。医生点击【就诊完成】：系统判断是否开具药品；无药品则订单流转至已完成、病历归档；存在药品则生成药品待缴费记录，挂号单进入待付款列表，附带【药品待缴费】标签；患者完成药费缴纳后病历归档。
开单药品规则:
药品下拉从药品管理接口加载，展示名称、单价；输入数量自动计算药品总金额
提交开药时校验库存；库存不足弹窗提示无法开具
生成药品待缴费记录，关联药品明细；患者缴费成功扣减库存；超时未缴费释放锁定库存
线下面诊卡片操作：【叫号】；点击叫号直接跳转病历开具页面，支持填写病历、选择是否开药；页面底部：过号按钮、查看历史病历；医生点击就诊完成，药品相关流转逻辑和线上保持一致。
个人排班管理
先是由日历的形式展示排班日期点击相应排班日期会展示排班信息弹窗（基础信息、时间段，类型，号源）下面有取消/申请停诊的按钮。
下面则具体展示医生个人排班记录，区分线上/线下类型，支持日期筛选时间段筛选；排班卡片附带【发起停诊申请】按钮；点击申请，弹窗填写排班日期、申请原因，提交停诊工单进入审批流。
申请管理
医生查看自己提交的停诊工单，实时查看审批节点与状态：待科主任审批、待替诊医生确认、待管理员复核、已驳回、已通过、已过期。
站内通知
通知分为普通通知、待审批通知两大板块；待审批通知独立展示并红点高亮。
通知内容包含：接诊提醒、停诊申请进度、替诊确认通知、审批驳回/通过通知。
审批流程：
医生提交停诊申请 → 科主任审批：
科主任驳回：流程结束，通知申请人；
科主任选择同意停诊：流转至管理员复核，管理员最终同意/驳回；
科主任选择安排替诊：选择备选替诊医生，后端校验该替诊医生该时段是否存在任意排班，存在则拦截提示不可选择；校验通过后发送替诊确认通知给替诊医生；替诊医生拒绝则打回科主任重新处理；替诊医生同意后，工单流转管理员复核；管理员最终同意/驳回。
替诊医生收到通知可选择同意替诊或者拒绝替诊；审批工单触发超时规则后标记为已过期，无法继续审批。
医生个人中心
基础信息展示、密码修改；
权限区分：普通医生仅查看自身信息；科主任额外拥有审批入口，可查看待审批的停诊工单，执行停诊/替诊审批操作。

管理员端（SpringBoot+Vue）
一、整体概述
管理员端为系统最高权限管理平台，负责系统基础数据维护、全局规则配置、药品库存管理、挂号费用配置、排班号源管理、停诊替诊最终终审、数据可视化统计、新闻公告发布。
本系统采用三级权限体系：普通患者、普通医生/专家、科主任、管理员，权限互不冲突。
医生分为：普通医生、专家医生（仅挂号费价格不同，权限完全一致）
科主任为审批权限身份，可叠加普通/专家身份，不单独产生挂号费。
所有系统核心规则（签到时间、过号时间、审批时效、出诊时段、挂号费、药品库存释放）全部支持后台动态配置，无需改代码。

用户管理（患者用户）

药品管理
全局参数配置（含时段、业务规则、挂号费配置、AI辅助配置）
申请审批管理（停诊、替诊终审）
新闻通知管理
个人中心

1. 首页（数据可视化大屏）
页面功能
展示系统全部运营统计数据与图表，直观监控平台运行状态。
统计卡片
总患者注册人数
在职医生总数
今日挂号总量
今日线上问诊量、今日线下面诊量
今日完成就诊量
今日爽约人数、今日过号人数
药品总品类数、库存预警药品数量

2. 用户管理（患者管理）
页面功能
对所有注册患者账号进行统一管理、查询、状态控制。
展示字段
账号、昵称、手机号、注册时间、爽约次数、账号状态
可执行操作
搜索、查看详情、禁用账号、启用账号、重置密码
校验&业务规则
被禁用患者无法登录、无法挂号、无法缴费

不支持删除已有挂号记录的用户（数据安全）
3. 医生管理（核心基础模块）
页面功能
新增、编辑、启用/禁用医生、设置医生类型、设置科主任权限
关键字段
头像、姓名、账号、职称、所属科室、擅长介绍、
医生类型（普通医生 / 专家医生）、
是否科主任、账号状态
核心业务规则（重要、全系统统一）
普通医生、专家医生：权限完全一致，仅挂号费不同
科主任只是审批权限，不单独产生挂号费
科主任挂号费跟随自身「普通/专家」类型自动匹配
四种合法医生身份组合：
普通医生、非科主任
专家医生、非科主任
普通医生、科主任
专家医生、科主任
禁用医生：无法登录、无法接诊、无法新增排班、无法提交停诊申请
页面校验
账号唯一、手机号唯一
所属科室必须选择有效启用科室
4. 科室管理
页面功能
新增科室、编辑科室、启用/停用科室、排序、查看详情
业务规则
停用科室后，患者端自动隐藏该科室
停用科室下所有排班自动失效、禁止新挂号
已有数据科室禁止删除，保证数据完整性
5. 排班管理（核心业务模块）
页面功能
管理员统一新增、编辑、查看、管理所有医生排班
医生无权自建排班，仅管理员可创建排班
排班核心硬性规则（全局固定、三端统一）
单条排班只能是【线上问诊】或【线下面诊】，不可混合
同一医生同一时间段不能存在任何排班（线上/线下全部冲突拦截）
排班时段分为上午、下午，具体时间由全局参数配置控制
排班创建自动填充规则
选择医生后，自动读取医生类型
自动带出【全局参数配置】中的默认挂号费
专家医生 = 专家默认挂号费
普通医生 = 普通默认挂号费
支持单条排班手动修改挂号费
优先级：单条自定义挂号费 ＞ 全局默认挂号费
页面校验规则
已有患者挂号的排班禁止删除、禁止修改时间、禁止修改类型
号源数量不可为负数
时间不能交叉冲突
6. 号源管理
页面功能
全局查看所有科室、所有医生每日号源情况
展示：总号源、剩余号源、已挂号人数
可执行操作
手动增补号源（医院应急加号）
业务规则
剩余号源为0时，患者端挂号按钮自动置灰
挂号成功自动扣减号源
停诊成功自动返还号源、取消所有订单
7. 药品管理（新增核心模块）
页面功能

（4）AI配置板块包含功能（贴合系统两个AI角色：患者端AI助手、医生端预问诊AI）
1. AI总开关（总启用/禁用）
配置项：AI辅助功能是否启用
作用：一键关闭全部AI能力（患者端AI助手、医生端症状摘要AI全部失效，AI窗口隐藏）
业务场景：接口欠费、维护、临时关闭AI
2. 患者端导诊AI配置（右下角那个问答助手）
AI回答边界提示词（系统提示词，文本框）
就是你之前做的围栏：限定只能回答医院地址、停车、科室、挂号流程、引导描述症状，不做诊断；兜底话术在这里配置。
多模态开关：是否允许上传图片（症状图片）
开启：患者可以传图给AI；关闭：仅文字对话
问答最大轮次限制：单轮对话最多多少轮（防止无限对话消耗额度）
兜底回复文案：当AI识别到超出范围问题时返回的固定提示（例如：我仅提供本院挂号咨询，不能给出诊疗诊断建议，请前往线下就诊）
3. 医生端预问诊AI配置（问诊室左侧，症状摘要AI）
摘要生成提示词模板：控制AI输出格式，只提炼症状、病史，禁止输出诊断结论、用药建议
是否自动生成摘要开关：医生和患者聊天后，是否自动调用AI生成摘要；关闭则需要医生手动点击【生成症状摘要】
摘要最大长度限制：控制返回文本长度，避免内容过长
多模态解析开关：是否解析患者上传的图片（比如患处照片）并入症状摘要
4. AI接口基础配置（对接第三方大模型API）
适合调用外部多模态API（比如兼容通义、千帆等）
API地址
API Key（密码框，掩码展示，保存加密存入数据库）
模型名称（下拉/输入：选择调用哪个多模态模型）
单次请求最大token上限
温度 temperature（建议限制输入范围0~1，控制AI随机性：越低越严谨，适合医疗场景，默认0.1~0.2）
5. AI日志策略配置
是否保存AI对话日志（患者端对话、医生端摘要记录）
日志自动保留天数（超过自动清理）
✅ 校验规则（前端+后端）
temperature 取值范围：0 ≤ temp ≤ 1，超出提示非法
token上限、轮次、天数：只能输入正整数
API密钥前端掩码展示，数据库加密存储，不明文回显
提示词内容增加长度限制，防止超长文本
关闭总开关时，子项配置保留，但系统不再调用AI接口
✅ 业务联动
患者端AI助手：读取【患者端导诊AI配置】
医生问诊室症状摘要模块：读取【医生端预问诊AI配置】
所有AI调用统一读取这套参数；修改后实时生效，不用重启后端

四、全系统统一最终业务规则
1. 医生身份规则
医生分为普通、专家两类，仅挂号费不同，权限一致
科主任为审批身份，可叠加任意医生类型，不单独定价
2. 挂号费规则
全局默认价格可配置
单条排班支持自定义价格，优先级最高
3. 排队、签到、爽约、过号规则
仅缴费成功+按时签到可进入接诊队列
排队优先级：预约挂号＞当日挂号，同类型按签到时间排序
过号重排：预约号放回预约队尾、当日号放回当日队尾
患者仅可恢复排队一次，二次过号作废
签到窗口、过号等待时长全部后台可配置
4. 药品库存规则
开药锁定库存、缴费成功扣减库存
超时未缴费自动释放库存
5. 停诊替诊审批规则
三级审批：医生→科主任→管理员终审
双重超时驳回，出诊前截止时限优先级最高
替诊严格校验时段所有排班冲突
6. 排班规则
单排班只能线上/线下二选一
同一医生时段不可重复排班
7. AI辅助规则（三端统一）
患者端AI：多模态导诊、科室推荐、FAQ
医生端AI：多模态提取医患对话症状生成摘要辅助问诊
管理员端：无需AI模块
五、三端最终闭环总结
患者端：挂号、缴费、签到、排队、线上图文问诊、药品缴费、查看病历、AI导诊
医生端：接诊、AI辅助问诊、写病历、开药、发起停诊、科主任审批替诊/停诊
管理员端：全局数据配置、排班
