## 业务边界

- 管理员只处理停诊与替诊最终终审，不混入医生资质或医疗访问审核。
- 管理员不能替换替诊医生；驳回后由申请链路重新选择。
- 患者只展示运营必要身份和挂号状态，不展示任何医疗正文。
