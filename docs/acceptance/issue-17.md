# #17 患者首页预约与就诊状态摘要

## 范围

首页读取患者本人 `/patient/appointments` 的最新预约摘要，分别展示预约、支付、签到、候诊、叫号、过号和完成状态；首页只提供下一步导航，不展示医疗正文。订单页继续承担支付、签到和恢复排队等服务端校验动作。
