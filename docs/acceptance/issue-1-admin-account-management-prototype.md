# 管理员账户管理原型验收记录

## 范围

本记录覆盖管理员端 A 版账户管理工作台 `/prototype/admin-accounts`。页面使用虚构内存数据，提供患者、医生和管理员的统一账户目录与账户治理操作，不连接真实账户接口，也不展示医疗正文、附件、预约内容或医生资质审核内容。

## 业务边界

- 账户角色在本页只读展示；医生资质、科主任任命和管理员授权走独立流程。
- 停用账户不会取消预约、停诊或删除历史医疗记录；登录锁定是安全处置状态。
- 账户管理只展示必要身份信息，医疗正文与附件需要独立医疗访问审核权限和审计理由。
