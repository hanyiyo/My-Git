# 总需求 #1：患者端首页交互原型

设计问题：将参考图的浅蓝/青绿医疗服务布局改为可收缩左侧栏后，首页应优先突出快捷服务、当前就诊还是导诊探索？

基线：8417a7e；本地原型分支：`codex/prototype-patient-home`。原型为独立的虚构患者工作区，沿用已有 `/prototype/` 路由约定；避免为预览设计修改共享的真实鉴权首页或要求真实患者登录。只在 Vite 开发环境注册，不修改业务接口。

入口：`npm run prototype:patient`，访问 `/prototype/patient-home?variant=A`。A=清新服务台，B=就诊时间线，C=导诊探索。URL 与底部切换器选择同一版本，左右键支持切换；输入与弹窗内不截获方向键。全部交互为内存演示，刷新重置。
