## 迟到成功付款切片

## 退款执行与恢复切片

退款执行测试先因管理处理接口缺少而失败（期望200、实际500）。实现后，退款意向由 MySQL 持久化领取租约、尝试令牌、错误、下次执行时间和每次尝试记录；模拟退款调用在事务外执行，写回必须匹配令牌。首次失败保存 `REFUND_FAILED`，到期后复用同一退款幂等键重试，成功变为 `REFUNDED` 并保存 provider reference；三次失败后停止继续调度。重复处理不重复调用或创建退款，取消订单始终保持取消状态。
