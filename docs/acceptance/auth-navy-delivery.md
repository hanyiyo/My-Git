# 深蓝登录注册页正式交付

来源：用户确认采用原型方案 A、深蓝主色，管理员账号仅由后台创建；身份约束依据 GitHub #2、MVP 规格、GLOSSARY、ADR-0014 和登录安全设计。

设计冻结为方案 A、深蓝主色和左右分栏。设计原始资料已归档到远程 [prototype/auth-layouts 分支的 e528d74](https://github.com/hanyiyo/My-Git/tree/e528d74)。正式实现使用 `/login` 的真实账号、验证码、CSRF 和会话接口，不将原型中的模拟登录、演示填充、模拟验证码或布局切换带入正式分支。

左侧选择患者、医生或管理员入口，右侧登录/注册表单。公开注册只允许患者和医生，管理员只显示登录与后台创建说明。从注册状态切换到管理员时回到登录。登录后的角色和跳转仍由服务端返回的账户角色决定，入口选择不授予权限。

注册仍按真实接口提交账号、密码与角色；密码保持 12–72 位规则，新增前端确认密码检查。显示名称、记住演示和找回密码的原型占位不进入正式表单；会话延续现有 HttpOnly Cookie 与内存 access token 策略。

交付验收发现：首张验证码尚在加载时完成注册，原刷新互斥会提前返回，导致注册成功提示丢失。现在重叠调用等待同一验证码请求结束，保持输入和提交禁用状态直到挑战就绪；新增受控延迟首张验证码的真实浏览器回归用例。
