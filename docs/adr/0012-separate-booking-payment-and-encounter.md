# 分别表达预约、付款、候诊和接诊状态

状态：accepted

双业务线 MVP 已确认按时签到候诊、叫号接诊和模拟退款。预约登记表达服务承诺，支付与退款表达费用处理，候诊表达到诊顺序，接诊及医疗记录表达医生提供的服务；因此这些概念分别保留状态，不用早期图文消息的 `open/replied/closed` 覆盖整个生命周期。

这是对 [ADR-0006](0006-consultation-and-ai-runtime-rules.md) 的状态边界细化：医生提交结果并结束接诊后预约完成、诊室只读；过了排班结束时间不能自动中断正在接诊的患者。取消后退款失败仍保持预约取消，退款可以独立重试。规则及待决项见 [接诊规则](../design/reception-rules.md)。

该选择增加了状态衔接和一致性验证成本，但可以避免付款成功即视为就诊完成、退款失败恢复停诊号源等错误。具体枚举、事务边界与状态迁移表在业务规则确认完后汇总。
