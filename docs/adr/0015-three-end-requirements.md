# 三端新规格替代早期MVP的队列、替诊和AI范围

状态：accepted。依据用户确认的R3-Q1–Q8，当前产品规格为[三端修订](../design/three-end-requirements.md)。本决策部分替代ADR-0003、ADR-0007、ADR-0009、ADR-0010、ADR-0011、ADR-0012中与下述范围冲突的部分，其他约束保留。

预约/当日类别按登记时日期固定，患者主动恢复一次后回原类别队尾；爽约与二次过号终止有效登记且不自动退款。替诊复核后新建排班并自动迁移，只通知患者，取消需患者主动操作；停诊自动取消退款。这样减少替诊等待，但必须保留更换医生和取消通知。

药品与库存、多模态导诊、医生摘要、运营统计纳入本次范围。医疗结果提交即保存，药费支付是独立生命周期，药费超时不销毁病历。旧患者预问诊摘要不再是主流程入口，历史记录保留受控访问。

业务规则版本在排班/挂号/叫号/审批/药费开始时保存，修改后台参数不追溯改变已有承诺；AI总开关立即生效。医疗材料外发仍需明确授权，管理员AI日志仅元数据，医疗正文最小权限与签名审计继续生效。代价是同时维护历史快照和当前配置，避免改价、改时间或改审批截止导致存量业务突然失效。
