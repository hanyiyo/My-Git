# 引入 Redis 支持登录图形验证码

用户在 Q1–Q66 后确认首版增加 Redis，并在账号密码登录前验证图形验证码。该验证码由本系统实际生成、校验，不发送短信或邮件；它不等于手机号所有权验证、实名认证或第二认证因素。

Redis 承担短期验证码状态和验证码获取/登录尝试的限流，MySQL 继续保存账户、可撤销刷新会话、预约占用、支付、候诊、持久任务和审计。此选择部分替代 [ADR-0013](0013-single-node-durable-runtime.md) 的“不引入 Redis”部署约束，持久任务及私有本地存储方案继续有效，不把预约正确性改为依赖 Redis 锁或过期事件。

代价是本机和 Linux 均增加一个依赖，Redis 故障时不能签发或绕过验证码登录；用户刷新页面后可重新获取，不承诺验证码状态跨 Redis 重启保留。登录规则、有效期等实现默认值见 [登录与 Redis](../design/login-security.md)，随架构草案整体审阅。
