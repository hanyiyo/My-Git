# 单机 MVP 依赖 MySQL 持久化任务和私有本地文件

当前目标是 Windows 演示和单台 Linux 部署，选择 REST 写入、SSE 推送并可回退轮询；MySQL 保存消息与后台任务，本地私有目录保存附件。相比引入 Redis、消息中间件和独立对象存储，这减少首版部署依赖，但要求任务幂等与重启恢复、消息查询补齐、数据库和附件联合备份。

MySQL 负责业务有效性校验与占用互斥，扫描只推进到期工作，不能代替接口实时校验截止时间。任务外部调用与业务事务分离，文件通过存储接口和后端鉴权访问；多节点扩容时需要重新设计共享文件与事件分发，不能只复制后端进程。详见 [技术基础](../design/technical-foundation.md)。
