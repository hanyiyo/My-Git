# 用可重建缓存保存临时工作区标签

状态：accepted。患者工作区使用独立页面承载“我的挂号”和医患图文诊室，并在智能医疗问诊预约系统标题下显示可关闭的临时工作区标签。标签树只保存当前患者打开了哪些导航入口及其展示参数，关闭标签立即移除该入口；刷新或重新登录后可以从缓存恢复，恢复失败不影响患者的预约、候诊、接诊或医疗记录。

Redis 只缓存按患者账户隔离的临时标签树，并设置有限 TTL（默认 24 小时）；MySQL 继续作为 Appointment、Waiting queue、Encounter、Consultation 和医疗结果的事实来源。这样可以让多页面工作区在短时间内保持连续，同时避免把导航状态误当成业务状态或用 Redis 承担预约一致性。

代价是 Redis 不可用或缓存过期时，患者会回到默认工作区，需要重新打开页面；产品不能把临时标签当作可靠历史记录，也不能因为标签恢复失败而恢复或改变任何预约操作。原型阶段可用前端状态模拟同一行为，接入真实 Redis 时保持该边界。
