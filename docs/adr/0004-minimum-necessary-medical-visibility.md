# 医生只访问患者主动共享的最小医疗范围

状态：accepted

医生默认只能看到当前 Appointment 相关的 Consultation 内容，以及 Patient 针对该预约主动共享的 Shared health record；系统不向医生默认暴露患者全部历史问诊或全部健康档案。选择这一边界是为了让医疗数据访问与具体照护场景绑定，并让患者能够明确知道哪些资料被共享。

## 后果

- 共享范围必须成为可审计的数据，而不是依赖前端隐藏字段。
- 医生查看历史资料时需要区分“当前问诊材料”“当前预约共享档案”和“未共享资料”。
- 管理员的审核和运维权限仍需单独建模，不能把管理员权限当作医生共享范围的例外说明。
