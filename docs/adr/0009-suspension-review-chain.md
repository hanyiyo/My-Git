# 科主任组织停诊方案，管理员复核排班变更

医生停诊会影响患者已获得的服务承诺，因此普通停诊流程采用科主任审核、替诊医生确认（仅替诊方案需要）、管理员复核后调整排班的职责链。科主任是医生账户上的科室权限，不是第四个系统端；医生须在出诊前至少 24 小时申请，紧急停诊由管理员办理。

本决策细化 [ADR-0003](0003-schedule-slot-appointment-lifecycle.md) 的排班审批职责，并替代“医生直接提交管理员”的简化路径。科主任选择直接停诊时无需虚设替诊医生确认步骤。

Q33–Q42 后续确认：直接停诊解除患者占用并停用整次出诊号源，患者重新选择其他有效排班；替诊经管理员复核后还需患者接受，接受前保留患者名额，替诊医生不能提前访问共享医疗材料。同科室、资质通过且时间不冲突的医生才可替诊，拒绝后回科主任重新选择或直接停诊；科主任自身申请交管理员审核，紧急停诊由管理员执行并记录理由。最终复核重新校验资质和排班。

正常患者确认截止时间取通知后 2 小时与出诊前 2 小时的较早值；未接受则取消退款并提醒，复核时已不足提前 2 小时则转人工紧急处理。患者选择或处置结果必须记录，不能视为已获得自动改派授权。退款及接诊细节见 [接诊规则](../design/reception-rules.md)。
