# 科主任组织停诊方案，管理员复核排班变更

医生停诊会影响患者已获得的服务承诺，因此普通停诊流程采用科主任审核、替诊医生确认（仅替诊方案需要）、管理员复核后调整排班的职责链。科主任是医生账户上的科室权限，不是第四个系统端；医生须在出诊前至少 24 小时申请，紧急停诊由管理员办理。

本决策细化 [ADR-0003](0003-schedule-slot-appointment-lifecycle.md) 的排班审批职责，并替代“医生直接提交管理员”的简化路径。科主任选择直接停诊时无需虚设替诊医生确认步骤；替诊医生拒绝后的回退、原预约迁移和停诊号源停用规则仍待确认，不能视为已获得自动改派授权。
