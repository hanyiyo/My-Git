# MVP 附件与后台能力保持受控范围

状态：accepted

MVP 只接受白名单内的图片和 PDF/常见文档作为 Medical attachment，并设置大小限制和安全扫描边界；语音输入延后到后续迭代，但 AI gateway 预留语音转文字能力。管理员首版覆盖账户、医生、科室、排班、预约、问诊审核和 AI 调用日志，医疗知识库、复杂统计和自动化运维监控后置。

## 后果

- 上传文件必须经过类型、大小和访问权限校验，不能直接把对象存储 URL 暴露给前端。
- OCR/图片分析可以异步处理，医生看到的结果可能处于待处理或失败状态。
- 后续增加语音、知识库或监控时，应扩展边界模块，不把首版的范围假设成最终产品范围。
