# 用会话工作区承载患者 AI 与医生沟通

状态：accepted。患者端“图文诊室”采用参考图式的会话工作区：左侧列出近一个月的 AI 助手会话和线上预约医生会话，中央显示当前选中的单个会话。订单中的“进入诊室”直接选中对应医生会话；顶部导航中的“图文诊室”默认选中 AI 助手会话。AI 和医生不使用同一消息流，也不要求同时显示两个输入框。

医生会话属于对应的 `Consultation`，线上预约结束后消息只读；线下面诊不创建医生聊天会话。患者 AI 助手使用独立的 `AI assistant session`，当前先支持文字输入，持续会话不代表医生意见、诊断或病历结论；医生端的 AI 辅助结果仍是独立的、患者不可见的 `Doctor symptom summary`。患者明确执行“发送给医生”后，才把选中的文字复制到医生会话，默认不共享。

近一个月的聊天记录进入业务持久化存储，供患者选择和查看；临时工作区标签仍按 [ADR-0017](0017-temporary-workspace-tabs.md) 使用 Redis 可重建缓存。这样可以同时满足会话可追溯和导航状态可过期，代价是聊天记录与临时标签采用不同的恢复和一致性规则。
