# 普通业务咨询、医疗预问诊和内容审核使用不同权限边界

普通业务咨询不要求医疗材料授权，AI 预问诊则在使用前弹窗确认提供方、用途和本次材料范围；拒绝授权仍能自行预约并使用医生服务。外部 AI 仍需显式配置启用，这是在 [ADR-0008](0008-explicit-external-ai-boundary.md) 上增加患者选择，不能由部署启用替代患者授权。

该区分让医院地址、流程查询保持轻量，同时避免把首页咨询入口变成医疗材料外发通道。具体症状导诊如何触发授权仍待确认。AI 调用日志默认只保留提供方、用途、状态、耗时和错误码等必要元数据，医疗正文与附件保存在独立受控的业务记录中。

普通管理员页面仅展示业务状态及必要身份信息；医疗正文和附件的审核需要独立授权、填写理由与记录访问日志，调用日志不展示医疗正文。本条细化 [ADR-0004](0004-minimum-necessary-medical-visibility.md) 的管理员访问边界，不授予管理员默认全量病历访问权。
