# 管理员账户管理原型

状态：已确认并实现。入口为 `/prototype/admin-accounts`，使用虚构演示数据，不连接真实管理员账户接口。

## 页面定位

账户管理属于管理员端“资源”模块，提供患者、医生、管理员的统一账户目录。页面只承担账户治理，不展示病历、医疗附件、预约正文或医生资质审核内容。

角色在本页只读展示。医生资质、科主任任命和管理员授权分别走对应业务流程；停用账户不会取消预约、停诊或删除历史医疗记录。

## 列表与筛选

列表展示姓名/账号、角色、来源、账户状态、最近登录和注册时间。手机号和邮箱在详情抽屉中脱敏展示。支持关键词、角色和启用/停用/登录锁定三类状态筛选，默认按最近登录时间倒序。

## 详情与操作

详情抽屉展示身份摘要、角色标签、启用/停用状态、登录锁定状态、状态变更时间、登录风险和最近 3 条治理操作记录，并提供“查看全部”入口。停用、解锁和重置登录状态属于高风险操作，需要二次确认并说明影响；启用和锁定可直接执行。

所有状态和操作记录均为虚构演示数据，页面不调用 `/api/`。

## 验收边界

- 管理员首页和预约工作台的资源导航可以进入账户管理；账户管理页可返回运营总览。
- 关键词、角色、三种状态筛选与最近登录排序可用，并同步到 URL。
- 账户详情抽屉只出现治理信息，联系方式脱敏，医疗内容不出现在页面中。
- 启用/停用、锁定/解锁、重置登录状态的状态变化可演示；高风险动作需二次确认。
- 桌面表格在窄屏保持可滚动，侧栏可打开/关闭，页面无横向溢出。
