# 管理员账户管理原型

状态：已合并到患者和医生资源工作台。旧入口 `/prototype/admin-accounts` 仅保留兼容跳转到 `/prototype/admin-patients`，使用虚构演示数据。

## 页面定位

账户治理属于管理员端“资源”模块，患者和医生详情抽屉分别承接对应账户的启用 / 停用、登录锁定和登录状态重置。页面不再提供独立的患者、医生、管理员统一账户目录，避免与资源工作台重复。

角色在本页只读展示。医生资质、科主任任命和管理员授权分别走对应业务流程；停用账户不会取消预约、停诊或删除历史医疗记录。

## 列表与筛选

患者页和医生页各自展示业务资料、账户状态与登录状态；手机号在详情抽屉中脱敏展示。筛选留在各资源页，不再维护重复的统一账户筛选。

## 详情与操作

患者和医生详情抽屉展示身份摘要、启用 / 停用状态、登录锁定状态和最近治理记录。停用、锁定、解锁和重置登录状态需要二次确认并说明影响。

所有状态和操作记录均为虚构演示数据，页面不调用 `/api/`。

## 验收边界

- 管理员首页和预约工作台不再展示独立账户管理入口；旧路径兼容跳转到患者页。
- 患者和医生详情抽屉只出现必要资料与治理信息，联系方式脱敏，医疗内容不出现在页面中。
- 启用/停用、锁定/解锁、重置登录状态的状态变化可演示；高风险动作需二次确认。
- 桌面表格在窄屏保持可滚动，侧栏可打开/关闭，页面无横向溢出。
