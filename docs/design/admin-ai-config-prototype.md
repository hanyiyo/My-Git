# AI 配置演示原型

关联总需求 #1。用户已确认在 `/prototype/admin-home?module=AI 配置` 内实现，沿用管理员运营壳层和全局规则的分组卡片、独立弹窗；不新增替代页面。

## 范围与默认值

五组为总开关、患者导诊、医生症状摘要、接口与模型、记录策略。总开关默认启用，运行模式默认本地演示。患者最大对话10轮（1–50），医生摘要1000字（100–5000），最大输出2048 token（128–32768），temperature默认0.2（0–1）；轮次、长度、token和保留天数为十进制正整数。提示词和模板必填、最多4000字，兜底文案必填、最多500字。图片上传及多模态解析默认关闭，自动摘要默认开启。

外部模式共用一套HTTPS接口、模型名和密钥状态，缺少任一项不能保存。地址不允许凭据、查询参数或片段，避免将密钥混入可显示地址；模型名最多100字、地址最多500字。演示仅提供“设置演示密钥/清除”，从不输入真实密钥，不在前端存储密钥。切回本地保留外部配置。本地演示没有真实图片解析能力。

记录策略默认保存调用元数据、保留30天（1–365）。关闭不删除既有记录，不改变受控医疗内容保留；该页不展示完整对话、正文或附件。保留 `/admin/ai` 调用记录入口，该正式页仍按登录权限加载元数据。

## 交互

总开关启用、停用均对比并确认。目标停用规则：隐藏患者AI入口、停止新生成，在途返回也不再发布新结果，保留子项与已有记录；实际外发材料无法通过停用撤回。本原型不联动其他页面或真实任务。

每次编辑一组，校验后展示当前值与新值，再确认保存；无实质变化不能提交，取消、Esc和遮罩关闭遇到未保存修改均确认放弃。确认前不更新卡片。保存显示运营管理员、Asia/Shanghai医院时间和会话内只读变更记录，密钥仅记录已配置/未配置。

独立测试弹窗测试当前已保存配置，选择模拟成功、连接失败或超时，显式执行后显示模拟结果；选择变化清空旧结果。没有真实网络请求或患者材料，失败不改变模式、不阻止合规配置保存。总开关关闭时仍可模拟连接测试，测试不生成医疗结果。

刷新保留已保存值与记录；浏览器重载或离开模块后恢复初始演示配置。新配置用于后续生成，不能扩大医疗材料授权；患者不诊断不开药，医生摘要仅供负责医生辅助接诊。原型没有真实配置保存、元数据清理或审计联动。

## 现有能力与接入差距

遵循[外部AI边界](../adr/0008-explicit-external-ai-boundary.md)、[授权和元数据边界](../adr/0010-assistant-consent-and-review-access.md)与[三端规格](../adr/0015-three-end-requirements.md)。不新增领域术语或ADR。

现有 `AdminAiView.vue` 仅显示调用元数据；规格中 `/admin/settings/ai` 和 `/settings/ai` 尚无配置模型、持久化或消费服务。唯一提供方为 `LOCAL_MOCK` 文本实现，`EXTERNAL_TEXT` 明确报提供方不可用，不会回退本地。后端没有总开关的新请求、队列重试及返回发布检查，也没有真实图片解析、自动摘要、限轮数或配置保留策略。

当前导诊图片输入尚不解析图片；医生摘要接口仅检查存在共享材料，尚未按获授权消息集合和提供方用途范围生成，也缺少摘要版本、自动生成与调用元数据链路。接真实配置前必须修复这些消费和授权链路，补充加密密钥管理、服务端校验、并发版本控制、权限、审计、外部适配器与失败行为；不能仅替换页面请求即宣称上述目标已生效。

## 验证

浏览器公开交互验证原入口、五组、默认值、总开关确认、四组保存、边界校验、无变更提交、关闭放弃、模拟密钥与三种测试结果、修改记录和刷新/重载、无真实请求、调用记录入口、桌面和手机布局与所有按钮样式。交付门禁为 `scripts/verify.ps1`，通过后创建Git提交。
