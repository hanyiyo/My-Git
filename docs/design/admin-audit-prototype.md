# 管理员审计日志原型

状态：用户已确认设计。关联总需求 #1，沿用 ADR-0004、ADR-0010、ADR-0015 的最小医疗可见性边界。

## 页面与数据

在现有 `/prototype/admin-home?module=审计日志` 内嵌工作台，复用管理员导航、图标和视觉风格。首版为稳定的虚构演示数据，不调用真实接口、不向浏览器持久存储写入数据。演示业务日取页面加载时的 Asia/Shanghai 日期，同次加载内数据保持稳定。

以管理员运营操作为主，覆盖账户、科室、排班、号源、药品库存、审批替诊、新闻和规则配置；医疗访问只展示必要操作信息，隐藏访问理由。医疗访问菜单保持隐藏。本页展示运营日志不代表各模块已经具备真实采集能力。

真实审计事件目前只有编号、操作者编号、动作、对象类型、对象编号、理由和时间。现有接口仅支持按对象查询，没有全局列表、分页及模块筛选接口；账户、普通排班、库存和新闻等事件尚未全部接入统一审计。接真实接口是后续工作，演示姓名和模块分类不是后端已存在的快照。

## 展示和交互

- 三张摘要卡片展示当前完整筛选结果的日志数、涉及管理员数和涉及模块数，统计不局限于当前分页。
- 筛选仅日期范围、业务模块、关键词。默认近 7 个医院业务日（含今天），关键词匹配操作者姓名/编号、操作名称、日志编号和业务编号；重置恢复默认日期和全部模块。日期缺失或开始晚于结束时提示修正，列表不显示误导性结果。
- 表格展示时间、操作者、模块、操作名称、对象和业务编号，以及查看详情入口。按时间倒序，同时间以日志编号稳定排序，每页 10 条；筛选变化回到第一页，空结果和无效日期有明确提示。
- 点击行、行上详情按钮或键盘进入右侧详情抽屉，显示完整日志编号、操作者编号、事件信息及可公开的操作说明。关闭按钮、Esc 和遮罩均可关闭，并恢复原焦点。
- 只读操作包括复制日志编号/业务编号和刷新。复制成功反馈，失败提供可手动复制的编号；抽屉内也能看到反馈。刷新保留筛选和页码，从演示数据重新读取并按编号同步抽屉，不生成业务事件、不修改原日志。
- 医院时间精确到秒，并标明 Asia/Shanghai。无编辑、删除、导出、关联业务操作跳转或模拟签名完整性校验。

## 隐私和验证

不展示医疗正文、附件原文、患者医疗内容、密码或密钥；不直接渲染自由填写的医疗访问理由。不添加缺乏数据依据的成功/失败、IP、修改前后值或异常告警。

浏览器验收覆盖入口、筛选和统计联动、日期边界、跨时区业务日、排序分页、详情与键盘、复制成功/失败、刷新同步、隐私边界、桌面/手机布局和按钮样式。完整交付须通过 `scripts/verify.ps1` 并创建 Git 提交。
