# 已确认的技术基础

Q52–Q54 已确认。范围见 [当前 MVP](current-mvp.md)；完整模块图和状态图将在访谈收敛后汇总。

## 图文消息和通知

REST 提交图文消息，成功入库后通过 SSE 推送新消息、叫号和站内通知。数据库记录为事实来源，连接不是医疗记录存储；断线重连后按查询游标补齐，客户端按消息标识去重。SSE 不可用时回退轮询，不把推送成功当作患者已经阅读。

发送和订阅都需要后端鉴权，按当前问诊归属与访问权限过滤；撤权、替诊和诊室结束必须限制后续操作。附件通过独立鉴权下载，不在事件载荷里公开本地路径或不受限地址。

## 持久化后台任务

AI 分析、占号超时、退款重试、替诊确认超时使用 MySQL 持久化任务，由 Spring Boot 后台执行器和定时扫描处理，支持抢占、超时恢复、有限重试和幂等。首版不依赖 Redis 或消息中间件。

执行按至少一次处理设计，恢复或重复执行不能造成重复占号、退款或通知业务记录。业务变更和任务写入应有一致性边界；预约有效性以事务中校验的数据库状态与截止时间为准，不依赖扫描器及时执行。不能长期占用医疗业务事务等待外部 AI 网络调用。

## 私有文件

服务器本地私有目录加数据库元信息，上传下载通过存储接口及后端鉴权，后续可替换为 MinIO 或其他对象存储。本地目录不属于前端静态资源，不把物理路径作为公开访问地址。

数据库与文件目录一起备份；上传完成、元信息落库失败的孤立文件需有可追踪清理方案。Q59 确认仅 JPEG、PNG、PDF，每份 10 MB、每次最多 5 份；检查实际格式与权限。仅虚构演示材料，已形成问诊记录不自动删除，管理员明确清理留痕；真实医疗保存政策需另定。不将存储接口当作已经完成内容安全校验。

文本材料和 AI 摘要版本分离：更新文本使旧结果过时，手动生成的新任务绑定材料版本、授权和提供方，失败不能覆盖已有结果；首版 AI 不自动外发附件。内容更换或授权失效时，任务执行前还需校验是否获准发送该材料版本。

## 部署边界

Windows 开发演示、单台 Linux 部署，一个 Vue 应用、一个 Spring Boot 后端和 MySQL。默认 mock/local AI，外部提供方需配置启用和患者授权；真实支付、短信和身份核验不在首版。
