# 管理员医院新闻工作台设计记录

## 范围

页面嵌入现有 `/prototype/admin-home?module=新闻通知`，使用稳定演示数据，承载管理员对医院公开资讯的运营管理。医院新闻面向患者和医生统一展示；个人业务提醒仍属于系统通知，不在本页维护。

## 页面结构

- 摘要卡片：全部内容、待发布（草稿与定时发布）、已发布、已撤回。
- 状态切换：全部、草稿、定时发布、已发布、已撤回；默认全部状态。
- 筛选栏：关键词、发布时间范围和重置；列表按更新时间倒序。
- 新闻表格：标题摘要、状态、发布时间、附件数量、更新时间和查看详情。
- 详情抽屉：正文、发布信息、封面与附件预览入口、状态允许的操作，以及内容边界提示。
- 新建/编辑弹窗：标题、摘要、正文、可选单张封面、最多三个图片/PDF 附件和发布方式。

## 状态规则

| 状态 | 可编辑 | 可执行动作 |
| --- | --- | --- |
| 草稿 | 是 | 保存、立即发布、删除 |
| 定时发布 | 是 | 修改时间、取消定时回草稿 |
| 已发布 | 否 | 撤回 |
| 已撤回 | 否 | 重新发布、只读查看历史 |

定时发布到达发布时间后自动转为已发布。定时发布必须选择未来时间；发布时标题和正文必填。首版不自动过期。撤回保留内容历史且不可再次编辑。

草稿详情提供“定时发布”快捷入口，打开编辑弹窗并预填未来时间。已撤回新闻保留原内容，管理员可通过“重新发布”恢复为已发布状态；重新发布不允许在历史版本上直接编辑。

## 验收边界

- 不展示患者个人通知、病历、症状、处方用法用量或医疗正文。
- 附件只接受图片或 PDF，最多三个；封面最多一张图片。
- 当前原型不调用后端接口，页面明确使用虚构演示数据；真实管理员新闻接口在后续阶段接入。
