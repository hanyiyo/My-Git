# 管理员排班管理原型

状态：已确认并实现 A 版原型。入口为 `/prototype/admin-schedules`，页面使用虚构演示数据，不连接真实排班、号源或预约接口。

## 页面定位

排班管理工作台负责管理员维护医生出诊安排。排班以“医生 + 日期 + 上午/下午 + 线上/线下”为一条出诊场次；发布后才产生患者可预约名额。预约履约、支付、退款和医疗内容继续由对应工作台处理。

## 页面结构

- 月历总览：按月份展示每日排班数量和状态摘要。
- 日期卡片：点击卡片主体切换右侧日期详情；卡片底部提供“新增排班”和“删除排班”按钮。
- 所选日期详情：按“上午 / 下午”分组展示当天排班；卡片采用时段、医生信息、状态与号源的左右分栏，避免信息挤在中间。
- 排班详情抽屉：点击排班卡片从右侧打开业务详情抽屉，查看医生、科室、服务方式、时段、费用、总号源、已挂号、临时占号、剩余号源和业务影响。
- 筛选栏：关键词、服务方式、排班状态和日历下拉日期。
- 详情操作：草稿可编辑和发布；已发布排班可暂停新增，并进入停诊 / 替诊复核。
- 排班表单：新增或编辑草稿时可选择“保存草稿”或“发布排班”；两个动作使用独立按钮，发布后立即开放号源。
- 表单反馈：医生未选择、时段冲突或号源无效时，错误提示固定显示在弹窗内并使用红色错误样式；日期统一通过日历下拉组件选择。
- 确认弹窗：暂停新增确认打开后，焦点自动落在确认按钮，便于键盘继续操作。

## 业务边界

- 管理员统一创建排班，医生端只能查看自己的排班并发起停诊申请。
- 单条排班只能选择线上问诊或线下面诊；上午固定 08:00–12:00，下午固定 14:00–18:00。
- 同一医生同一日期同一时段不能重复排班，线上和线下也不能并存。
- 排班状态分为草稿、已发布、暂停新增、已停诊、已替诊和已结束；号源使用单独展示。
- 没有患者挂号的排班可以删除；已有患者挂号的排班禁止删除，也不能修改日期、时段或服务方式。
- 停止新增只暂停新挂号，已有支付预约保留；停诊和替诊进入审批与替诊复核流程。
- 排班页不直接修改预约、支付、退款、患者资料或医疗内容。

## 访问路径

管理员首页、预约订单页和患者 / 医生 / 科室资源页的“排班”导航均进入 `/prototype/admin-schedules`。
